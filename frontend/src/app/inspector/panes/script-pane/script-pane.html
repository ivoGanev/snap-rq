Beta

Scripts run when you send a request they're attached to, in the order they were attached. Their tests and console output appear under Scripts in the response. 

function beforeRequest(req, ctx) {{ '{' }}
  req.headers.set('Authorization',
    'Bearer ' + ctx.env.get('TOKEN'));
{{ '}' }}

function afterResponse(res, ctx) {{ '{' }}
  ctx.test('status is 200', () =>
    ctx.expect(res.status).toBe(200));
{{ '}' }}
req
method, url, body, headers.get / set / remove / all
res
status, body, json(), headers.get / all, durationMs
ctx
env.get, vars.get / set, test, expect, skip
console
log, info, warn, error

Ordering scripts per request and writing variables are still in progress. To see them sooner, consider supporting development.
